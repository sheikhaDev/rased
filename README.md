# الأمان عبر الإنترنت – إنشاء كلمة مرور قوية وحمايتها

درس إلكتروني تفاعلي باللغة العربية لمادة تقنية المعلومات، الصف الخامس الأساسي (الوحدة الثالثة: الإنترنت، الدرس الرابع).
أُنتج لمقرر ED634 (تصميم وإنتاج البرمجيات التعليمية).

## تشغيل الدرس
1. فك ضغط الملف.
2. افتح `index.html` بمتصفح حديث (Chrome أو Edge أو Safari). لا يحتاج إنترنت ولا خادمًا ولا تسجيل دخول.

## بنية المشروع
- `index.html`: هيكل الواجهة (الشريط العلوي، منطقة الشاشة، شريط التنقل، النوافذ).
- `style.css`: التصميم (16:9، RTL، ألوان الدرس).
- `script.js`: الشاشات والأنشطة والتقويم وحفظ التقدم والصوت.
- `assets/images`: الرسوم SVG (shield, lock-closed, lock-open).
- `assets/audio`: التعليق الصوتي (home, what, props, create, end) وملف اختياري `applause.mp3` للتصفيق.

## الشاشات (14 شاشة)
الرئيسية، الأهداف، ما كلمة المرور؟، لماذا نحتاجها؟، الخصائص، المقارنة، الحماية، ثم 4 أنشطة، الملخص، التقويم الختامي (عبر منصة Wayground)، ثم الختام، الختام.

## الأنشطة
1. اختر كلمة المرور الأقوى. 2. صنّف (سحب وإفلات أو نقر). 3. كوّن كلمة مرور (مقياس القوة). 4. احمِ حسابك (مواقف).
في كل نشاط: تلميح، تغذية راجعة صوتية ونصية، وإعادة محاولة. لا ينتقل الطالب قبل إكمال الشاشة.

## الصوت
- التعليق الصوتي بصوت المعدّة، سُرّع 1.2 مرة وحُذف منه الصمت الطويل.
- صوت الخطأ مُولَّد برمجيًا. للتصفيق: ضعي الملف `assets/audio/applause.mp3` ثم غيّري `APPLAUSE_FILE=false` إلى `true` في أول `script.js`، وإلا يُستخدم تصفيق مُولَّد برمجيًا.
- إن أضفت تصفيقًا من الإنترنت فتأكد من أن ترخيصه يسمح بالاستخدام التعليمي (مثل CC0)، واذكر مصدره هنا.

## الخصوصية
لا تُجمع بيانات شخصية. التقدم يُحفظ في `sessionStorage` أثناء الجلسة فقط.

## البرامج والتقنيات المستخدمة
- HTML5 وCSS3 وJavaScript (بدون مكتبات خارجية).
- SVG لرسم الشعار وقفل الدرس، وWeb Audio API لأصوات التغذية الراجعة.
- sessionStorage لحفظ التقدم، وتصميم متجاوب بوحدات cqw.
- ffmpeg لتسريع التسجيلات الصوتية وحذف الصمت.
- Playwright (Chromium) لاختبار الدرس آليًا.
- بُني الدرس بمساعدة Claude من Anthropic، بناءً على الستوري بورد وخريطة المحتوى من إعداد الطالبة. يجب الإفصاح عن استخدام الذكاء الاصطناعي وفق لوائح الجامعة.
- المصدر المرجعي للتصميم: الستوري بورد (iSpring Suite) المرفق في الواجب الأول.

## الرفع على GitHub (وتشغيله كموقع)
1. أنشئ حسابًا على github.com ثم اضغط **New repository**، واكتب اسمًا مثل `password-lesson`، وجعله **Public**، ثم **Create repository**.
2. اضغط **uploading an existing file**، واسحب **محتويات** المجلد بعد فك الضغط (index.html وstyle.css وscript.js ومجلد assets وREADME.md)، ثم **Commit changes**.
3. لتشغيله كموقع: **Settings ← Pages ← Source: Deploy from a branch ← Branch: main و / (root) ← Save**.
4. بعد دقيقة يظهر الرابط: `https://اسم-المستخدم.github.io/password-lesson/`.
